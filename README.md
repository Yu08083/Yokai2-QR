# 妖怪ウォッチ QRエディター

- [妖怪ウォッチ2用](https://yu08083.github.io/Yokai2-QR/)
- [妖怪ウォッチ3用](https://yu08083.github.io/Yokai2-QR/yw3/)

アイテムを選んでQRを表示する、ブラウザー用のエディターです。2用・3用は同じUIの独立したページです。

- 同じアイテムのQRを順番に表示
- セーブごとの手動の使用メモと、記録済みQRのスキップ
- QR画像とQRデータの保存・読み込み
- ツチノコパンダのすれちがい送信用の特殊QR

3用はスキヤキ日本版の報酬表に対応しています。更新版は179種類、本体版は133種類の受け取り内容を選べます。複数アイテム・数量の違い・抽選を区別しています。アイテムIDや数量を任意に指定する機能ではありません。QRの認証と報酬表はゲームのコードから確認していますが、すべての報酬を実機で検証したものではありません。

使用メモは作品・セーブごとにブラウザー内へ保存されます。ゲームの使用履歴とは連動しません。端末を変える場合は、メモを保存して対応する作品のページで読み込んでください。2用の既存のメモは引き続き使えます。

GitHub Pagesでは、mainブランチのルートを公開元に指定します。
