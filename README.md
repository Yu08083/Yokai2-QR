# 妖怪ウォッチ QRエディター

- [妖怪ウォッチ2用](https://yu08083.github.io/Yokai2-QR/)
- [妖怪ウォッチ3用](https://yu08083.github.io/Yokai2-QR/yw3/)
- [バスターズ 赤猫団・白犬隊・月兎組用](https://yu08083.github.io/Yokai2-QR/busters/)

アイテムを選んでQRを表示する、ブラウザー用のエディターです。各作品は同じUIの独立したページです。

- 同じアイテムのQRを順番に表示
- セーブごとの手動の使用メモと、記録済みQRのスキップ
- QR画像とQRデータの保存・読み込み
- ツチノコパンダのすれちがい送信用の特殊QR
- パスワードと受け取り内容の一覧・検索・コピー
- 3用・バスターズ用のP1ZZZY特殊QR

パスワードは2用に170件を掲載しています。3用はスシ・テンプラ・スキヤキ更新版36件、スキヤキ本体版21件、スシ・テンプラ本体版6件を掲載しています。「解析パスワードも表示」を有効にすると、入力原文が不明の22件（スシ・テンプラ本体版は19件）に対応する別の文字列も表示できます。解析パスワードはROMのCRC32照合値に一致するよう構成した文字列で、配布時の原文ではありません。スキヤキ更新版の元のARM判定・報酬情報取得処理で照合を検証しています。解析パスワードを含む掲載全件の実機での受け取りを、作者が確認済みです。同じ報酬枠の使用フラグを共有します。

3用は日本版のスシ・テンプラ・スキヤキの本体版・更新版の報酬表に対応しています。スシ・テンプラ・スキヤキ更新版は179種類、スキヤキ本体版は133種類、スシ・テンプラ本体版は90種類の受け取り内容を選べます。比較したスシ・テンプラ本体版の表は同一、3作品の更新版もQR・パスワードの表は同一です。複数アイテム・数量の違い・抽選を区別しています。アイテムIDや数量を任意に指定する機能ではありません。QRの認証と報酬表はゲームのコードから確認しています。掲載しているQRの受け取り内容は全件、作者が実機で確認済みです。

バスターズ用は、提供された赤猫団・白犬隊の本体版と白犬隊の更新データから作成しています。本体版はQR報酬表961行・パスワード193件、更新版はQR報酬表1282行・パスワード199件です。月兎組モードは246種類の受け取り内容を選べます（本体版186種類、白犬隊更新版の通常モード187種類）。報酬表にあっても先行する別の行に判定される種類は、選択一覧に載せません。更新版の元のARM処理でQR認証、全1282行の読み込み、両モードの報酬分岐（2564例）を照合済みです。赤猫団の更新データは未提供で、月兎組の表は白犬隊更新データを出典としています。バスターズの実機での受け取りは未検証です。

バスターズのP1ZZZZは専用フラグを設定し、更新版のP1ZZZYはセーブ内の状態ビットと管理値を解除します。どちらも通常のアイテム付与を行わず、「使用済み」の応答になります。本体版にはP1ZZZYの専用処理はありません。3用のP1ZZZYも引き継ぎ状態変更用で、アイテム・妖怪の受け取りには使いません。

使用メモは作品・セーブごとにブラウザー内へ保存されます。バスターズは赤猫団・白犬隊の各3セーブを区別し、月兎組は元のセーブのメモを使います。ゲームの使用履歴とは連動しません。端末を変える場合は、メモを保存して対応する作品のページで読み込んでください。2用の既存のメモは引き続き使えます。
