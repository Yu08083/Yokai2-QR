# 妖怪ウォッチ QRエディター

- [妖怪ウォッチ1（3DS）用](https://yu08083.github.io/Yokai2-QR/yw1/)
- [妖怪ウォッチ2用](https://yu08083.github.io/Yokai2-QR/)
- [妖怪ウォッチ3用](https://yu08083.github.io/Yokai2-QR/yw3/)
- [妖怪三国志用](https://yu08083.github.io/Yokai2-QR/sangokushi/)
- [バスターズ 赤猫団・白犬隊・月兎組用](https://yu08083.github.io/Yokai2-QR/busters/)
- [バスターズ2 ソード・マグナム用](https://yu08083.github.io/Yokai2-QR/busters2/)

アイテムを選んでQRを表示する、ブラウザー用のエディターです。各作品は同じUIの独立したページです。

妖怪三国志用は、日本版の本体・更新・追加コンテンツから作成しています。旧2桁形式246行・新3桁形式1033行に対応し、31種類の受け取り内容を選べます。パスワード16件はROMの入力原文と報酬表から掲載しています。本体版・更新版の表は共通で、3セーブの手動の使用メモ、連番表示、QR画像の読み込み・保存を利用できます。元のゲームの認証・報酬照合を実行して確認しています。実機での読み取り・受け取りは未検証です。

初代（3DS日本版）用は、提供された本体CIAと更新CIAから作成しています。QR報酬表240行にある16種類の報酬と、ROMに入力文字列が収録されているパスワード26件を掲載しています。本体版・更新版の報酬表を選び、QRの生成・画像読み込み・連続表示・セーブごとの手動の使用メモとパスワード一覧を利用できます。提供された更新データにこれらの表の差し替えはありません。初代の実機での読み取り・受け取りは未検証です。

- 同じアイテムのQRを順番に表示
- セーブごとの手動の使用メモと、記録済みQRのスキップ
- QR画像とQRデータの保存・読み込み
- ツチノコパンダのすれちがい送信用の特殊QR
- パスワードと受け取り内容の一覧・検索・コピー
- 3用・バスターズ用・バスターズ2用の引き継ぎ回数リセット（P1ZZZY）

パスワードは2用に170件を掲載しています。3用はスシ・テンプラ・スキヤキ更新版36件、スキヤキ本体版21件、スシ・テンプラ本体版6件を掲載しています。「解析パスワードも表示」を有効にすると、入力原文が不明の22件（スシ・テンプラ本体版は19件）に対応する別の文字列も表示できます。解析パスワードはROMのCRC32照合値に一致するよう構成した文字列で、配布時の原文ではありません。スキヤキ更新版の元のARM判定・報酬情報取得処理で照合を検証しています。解析パスワードを含む掲載全件の実機での受け取りを、作者が確認済みです。同じ報酬枠の使用フラグを共有します。

3用は日本版のスシ・テンプラ・スキヤキの本体版・更新版の報酬表に対応しています。スシ・テンプラ・スキヤキ更新版は179種類、スキヤキ本体版は133種類、スシ・テンプラ本体版は90種類の受け取り内容を選べます。比較したスシ・テンプラ本体版の表は同一、3作品の更新版もQR・パスワードの表は同一です。複数アイテム・数量の違い・抽選を区別しています。アイテムIDや数量を任意に指定する機能ではありません。QRの認証と報酬表はゲームのコードから確認しています。掲載しているQRの受け取り内容は全件、作者が実機で確認済みです。

バスターズ用は、提供された赤猫団・白犬隊の本体版と両作品の更新データから作成しています。本体版はQR報酬表961行・パスワード193件、更新版はQR報酬表1282行・パスワード199件です。月兎組モードは246種類の受け取り内容を選べます（本体版186種類、更新版の通常モード187種類）。両作品の更新版のQR・パスワード・報酬名のデータはSHA-256まで一致し、通常モードと月兎組の表を共通化しています。ゲームのコードは作品を区別する1バイトだけが異なり、QR認証・報酬・特殊QRの処理は同一です。報酬表にあっても先行する別の行に判定される種類は、選択一覧に載せません。両更新版の元のARM処理でQR認証、各1282行の読み込み、両モードの報酬分岐（計5128例）と各199件のパスワードの読み込みを照合済みです。バスターズの実機での受け取りは未検証です。

特殊QRは「ツチノコパンダ（P1ZZZZ）」「引き継ぎ回数リセット（P1ZZZY）」と表記しています。バスターズではツチノコパンダが専用フラグを設定し、更新版の引き継ぎ回数リセットがセーブ内の状態ビットと管理値を解除します。どちらも通常のアイテム付与を行わず、「使用済み」の応答になります。本体版には引き継ぎ回数リセットの専用処理はありません。3用の引き継ぎ回数リセットもアイテム・妖怪の受け取りには使いません。

バスターズ2用は、ソード・マグナムの本体版・更新版に対応しています。両作品は同じQR・パスワード表を使い、本体版はQR報酬表2394行、更新版は2395行です。重なった範囲ではゲームと同じく先に一致する行を優先します。受け取り処理が拒否する旧コインのIDと、先行する行に判定される報酬は選択一覧から外しています。本体版は505種類、更新版は506種類のQRを選べます。条件やQR情報の違いを区別した数で、表示名はそれぞれ229種類・230種類です。更新版のQ6Jはジルコンストーン∞、本体版の同じ種類はコインの抽選になります。

バスターズ2のパスワードは、[レベルファイブ公式で公開されている14件](https://www.youkai-watch.jp/busters2/guide/card-arcade/)をROMのCRC32登録値と照合して掲載しています。いずれも鉄鬼ストーンを受け取る別々の枠です。4版それぞれの元のARM処理でQR認証、全報酬行の読み込み・選択・返却値とパスワード照合を確認しています。パスワードの正常・異常入力と範囲外番号は計80例を検証しました。実機での読み取り・入力・受け取り、セーブの永続化は未検証です。提供された追加コンテンツ全4件にはQR・パスワードの報酬表はありません。

バスターズ2のツチノコパンダ（P1ZZZZ）は専用フラグを設定し、引き継ぎ回数リセット（P1ZZZY）はセーブ内の状態ビットを解除します。本体版・更新版とも専用分岐があり、通常のアイテム付与は行わず「使用済み」の応答になります。通常の旧2桁QRは旧コインのIDが登録されていないため受取対象外です。

使用メモは作品・セーブごとにブラウザー内へ保存されます。バスターズは赤猫団・白犬隊の各3セーブを区別し、月兎組は元のセーブのメモを使います。ゲームの使用履歴とは連動しません。端末を変える場合は、メモを保存して対応する作品のページで読み込んでください。2用の既存のメモは引き続き使えます。

バスターズ2の使用メモは、ソード・マグナム各2セーブで別々に保存します。ゲームの版を切り替えると同じ番号のセーブを選びます。使用メモだけを手動で切り替えた場合は、報酬表を変更しません。
