# 妖怪ウォッチ QRエディター

- [妖怪ウォッチ2用](https://yu08083.github.io/Yokai2-QR/)
- [妖怪ウォッチ3用](https://yu08083.github.io/Yokai2-QR/yw3/)

アイテムを選んでQRを表示する、ブラウザー用のエディターです。2用・3用は同じUIの独立したページです。

- 同じアイテムのQRを順番に表示
- セーブごとの手動の使用メモと、記録済みQRのスキップ
- QR画像とQRデータの保存・読み込み
- ツチノコパンダのすれちがい送信用の特殊QR
- パスワードと受け取り内容の一覧・検索・コピー

パスワードは2用に170件を掲載しています。3用はスキヤキ・テンプラ更新版36件、スキヤキ本体版21件、スシ・テンプラ本体版6件を掲載しています。「解析パスワードも表示」を有効にすると、入力原文が不明の22件（スシ・テンプラ本体版は19件）に対応する別の文字列も表示できます。解析パスワードはROMのCRC32照合値に一致するよう構成した文字列で、配布時の原文ではありません。スキヤキ更新版の元のARM判定・報酬情報取得処理で照合を検証しています。実機での受け取りは未検証です。同じ報酬枠の使用フラグを共有します。

3用は日本版のスキヤキ本体・更新版、スシ本体、テンプラ本体・更新版の報酬表に対応しています。スキヤキ・テンプラ更新版は179種類、スキヤキ本体版は133種類、スシ・テンプラ本体版は90種類の受け取り内容を選べます。比較したスシ・テンプラ本体版の表は同一、テンプラ更新版とスキヤキ更新版も同一です。スシ更新版は未確認です。複数アイテム・数量の違い・抽選を区別しています。アイテムIDや数量を任意に指定する機能ではありません。QRの認証と報酬表はゲームのコードから確認していますが、すべての報酬を実機で検証したものではありません。

使用メモは作品・セーブごとにブラウザー内へ保存されます。ゲームの使用履歴とは連動しません。端末を変える場合は、メモを保存して対応する作品のページで読み込んでください。2用の既存のメモは引き続き使えます。

GitHub Pagesでは、mainブランチのルートを公開元に指定します。
