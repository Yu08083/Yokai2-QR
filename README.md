# 妖怪ウォッチ2 QRエディター

https://yu08083.github.io/Yokai2-QR/

アイテムを選んでQRを表示する、ブラウザー用のエディターです。

- 同じアイテムのQRを順番に表示
- セーブ1・2・3ごとの使用メモと、記録済みQRのスキップ
- QR画像とQRデータの保存・読み込み
- ツチノコパンダの特殊QR

使用メモはブラウザー内に保存されます。端末を変える場合は、メモを保存して読み込んでください。

GitHub Pagesでは、mainブランチのルートを公開元に指定します。
